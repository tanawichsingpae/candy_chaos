# Candy Chaos

เกมยิงมุมมองจากด้านบน 2D ใน Unity 6.6 ภาพเยลลี่สีพาสเทล เล่นได้บน PC และจอสัมผัสแนวนอน

## เนื้อหาเกม

- แคมเปญ 3 ด่านที่มีฉากต่างกัน: สวนเยลลี่สีเขียว, ทะเลทรายคาราเมล, ทุ่งหิมะน้ำตาล และด่านพิเศษล่าคริสตัล 2 ครั้ง
- ฉากเปิดเรื่อง 5 หน้าแบบภาพเต็มหน้า เล่าเรื่องคริสตัลสายรุ้ง พายุแยม เหล่าขนมตัวแสบ ผู้พิทักษ์ทั้งห้า และเส้นทางสามด่าน ก่อนเลือกตัวละคร
- เลือกผู้พิทักษ์ได้ 5 ตัว: มาร์ชเมลโลว์, สตรอว์เบอร์รี, บลูเบอร์รี, จอมเวทน้ำตาล และมือสไนเปอร์ แต่ละตัวมีค่าสถานะ อาวุธ และพลังพิเศษเฉพาะ
- ศัตรูปกติ 11 แบบ รวมโดนัท คุกกี้ มาการอง ไอศกรีม และกัมมี พร้อมบอสประจำด่าน 3 ตัว
- ศัตรูตัวใหญ่พิเศษ 7 แบบปรากฏเป็นช่วงระหว่างด่าน: เยลลี่แตกเป็นลูกเยลลี่ 3 ตัวเมื่อแพ้, คัพเค้กระเบิดรอบตัว, โดนัทยิงกระสุนรอบทิศ, คุกกี้ยิงเป็นชุด, มาการองพุ่งเร็ว, ไอศกรีมยิงน้ำแข็งชะลอผู้เล่น และกัมมีเรียกลูกน้อง
- เหรียญลูกอมทองใช้เป็นของเก็บและไอคอนใน HUD; กระสุนศัตรูมีภาพแยม คาราเมล น้ำแข็ง และมินต์ที่แยกสีกันชัดเจน
- ความยากค่อย ๆ เพิ่ม: ช่วงต้นสวนเยลลี่เริ่มจากเยลลี่สีชมพูและคัพเค้กก่อน ศัตรูชนิดอื่นทยอยเข้ามาภายหลัง ด่านแรกและด่านสองมีตัวใหญ่พิเศษสูงสุดด่านละ 1 ตัว ด่านสามสูงสุด 2 ตัว; ศัตรูหยุดเกิด 8 วินาทีก่อนบอสและลดจำนวนศัตรูสมทบระหว่างสู้บอส รางวัลเหรียญหลังผ่านด่านเพิ่มขึ้นเพื่อให้ซื้ออัปเกรดได้ต่อเนื่อง
- ยิงอัตโนมัติเมื่อไม่เล็งเอง; กดเมาส์หรือแตะฝั่งขวาเพื่อเล็งยิง
- เก็บน้ำตาลเพื่อเลือกอัปเกรดระหว่างเล่น โดยมีตัวเลือกเปลี่ยนวิธียิงอย่างน้อยหนึ่งอย่างในแต่ละครั้ง เช่น กระสุนหลายนัด ทะลุ น้ำแข็ง ไฟ พิษ เด้ง หรือความเร็วกระสุน; ตัวละครสามตัวแรกมีอัปเกรดเฉพาะอาวุธของตนเองด้วย
- เมนู, หยุดเกม, แพ้/ชนะ, เซฟลูกอมและคะแนนสูงสุด และโหมดไม่สิ้นสุดหลังชนะ
- UI โทนม่วงเข้มแบบลูกกวาด พร้อมปุ่มนูนสีสด แถบพลังเงาวาว และการ์ดอัปเกรดที่มีไอคอน
- เสียงเอฟเฟกต์และดนตรีสร้างในโค้ด ไม่ต้องดาวน์โหลดเสียงเพิ่ม: ตัวละครทั้ง 5 มีเสียงยิงและพลังพิเศษต่างกัน พร้อมเสียงกระสุนน้ำแข็ง ไฟ พิษ กระสุนเด้ง และสกิลศัตรูตัวใหญ่

## เปิดโปรเจกต์

1. เปิด Unity Hub แล้วเลือก **Add project from disk** ชี้ไปที่ `D:\candy_chaos`
2. เปิดด้วย Unity Editor **6000.6.7f1**; รอ Import ครั้งแรกให้เสร็จ
3. ระบบตั้งค่าจะสร้าง `Assets/Scenes/CandyChaos.unity` อัตโนมัติ
4. กด **Play** ที่ด้านบน Unity Editor

ถ้าหน้าจอยังว่างหลัง Import ให้เปิด `Assets/Scenes/CandyChaos.unity` แล้วกด Play

## วิธีเล่น

| อุปกรณ์ | เดิน | เล็งยิง | ยิงอัตโนมัติ |
| --- | --- | --- | --- |
| PC | WASD / ปุ่มลูกศร | คลิกเมาส์ค้าง | ปล่อยเมาส์ |
| มือถือ/แท็บเล็ตแนวนอน | ลากนิ้วฝั่งซ้าย | แตะ/ลากนิ้วฝั่งขวา | ปล่อยนิ้วฝั่งขวา |

ฉากเปิดเรื่องกด **หน้าถัดไป**, **หน้าก่อน** หรือ **ข้ามเรื่องราว** ได้ บน PC ใช้ปุ่มลูกศรซ้าย/ขวาเพื่อเปลี่ยนหน้า และ `Esc` เพื่อข้าม บนมือถือปัดซ้าย/ขวาที่ภาพได้

กด `Esc` บน PC หรือปุ่ม `Ⅱ` ในเกมเพื่อหยุดชั่วคราว

กด `Space` บน PC หรือปุ่ม **พลังพิเศษ** บนจอสัมผัสเพื่อใช้ท่าเฉพาะตัว:

- มาร์ชเมลโลว์: กระสุนใหญ่ระเบิดเป็นวงเล็กเมื่อชนศัตรู; Sugar Bomb ยิงลูกระเบิดขนาดใหญ่ที่มีรัศมีกว้างขึ้น
- สตรอว์เบอร์รี: กระสุนแยมเคลื่อนที่ช้ากว่าและทิ้งแอ่งแยมเมื่อกระทบหรือหมดระยะ ศัตรูที่เหยียบแยมจะเดินช้าลง; Jam Storm ยิงแยมรอบตัวพร้อมสร้างแอ่งแยมหลายจุด
- บลูเบอร์รี: กระสุนปกติแช่เย็นศัตรูให้เดินช้าลง; Blizzard Shield ป้องกันความเสียหายชั่วคราวและแช่แข็งศัตรูรอบตัว
- จอมเวทน้ำตาล: ยิงกระสุนกระจายวงกว้าง; Magic Bloom ปล่อยคลื่นกระสุนรอบตัวและสร้างวงพลังชั่วคราว
- มือสไนเปอร์: ยิงแรงแต่ช้าและทะลุศัตรู; Golden Focus เพิ่มพลังยิงชั่วคราว

อัปเกรดกระสุนน้ำแข็งทำให้ศัตรูช้าลง กระสุนไฟเผาต่อเนื่อง กระสุนพิษสะสมความเสียหาย และกระสุนเด้งเลือกเป้าหมายใกล้เคียง อัปเกรดเหล่านี้ใช้ร่วมกันได้

อัปเกรดเฉพาะตัว: **ระเบิดน้ำตาล** เพิ่มรัศมีระเบิดมาร์ชเมลโลว์, **แยมเข้มข้น** เพิ่มขนาดและเวลาของแอ่งแยม, **น้ำแข็งจัด** เพิ่มความแรงของการชะลอและระยะเวลาแช่เย็น ไอคอนเฉพาะของทุกอัปเกรด รวมแม่เหล็ก ความเร็ว เพิ่มพลังชีวิต และฟื้นเลือด จะแสดงบนหน้าจอเลือกพลัง

ด่านพิเศษปรากฏหลังผ่านด่านหลัก 1 และ 2: เก็บคริสตัล 10 ชิ้นใน 60 วินาทีเพื่อรับโบนัสและฟื้นพลังชีวิต ศัตรูในด่านพิเศษเกิดทีละตัว

เมื่อแพ้ สามารถเลือก **ลองด่านนี้อีกครั้ง** เพื่อเริ่มที่ต้นด่านเดิมพร้อมพลังชีวิตและอัปเกรดตอนเข้าด่านนั้น หรือเลือกเริ่มใหม่ตั้งแต่ด่าน 1 จุดเริ่มใหม่นี้ใช้ได้ระหว่างการเล่นครั้งปัจจุบัน

## สร้างไฟล์เกม

- **Windows:** เปิด `File > Build Profiles` แล้วเพิ่ม Windows build profile, จากนั้น Build
- **Android:** ติดตั้ง `Android Build Support` พร้อม `OpenJDK` และ `Android SDK & NDK Tools` ผ่าน Unity Hub ก่อน แล้วเพิ่ม Android build profile และ Build
- **iOS:** ต้องใช้ Unity Editor บน macOS และติดตั้ง iOS Build Support

ตัวเกมแสดงผลแนวนอน โดยใช้ภาพต้นฉบับใน `Assets/CandyChaos/Resources/Art/` และรันเกมจากสคริปต์ใน `Assets/CandyChaos/Scripts/`

ฟอนต์ภาษาไทย `Noto Sans Thai` ถูกฝังไว้ใน `Assets/CandyChaos/Resources/Fonts/` เพื่อให้ข้อความแสดงผลเหมือนกันบน Windows, Android, iOS และ Web build โดยไม่ต้องพึ่งฟอนต์ที่ติดตั้งในเครื่องผู้เล่น
